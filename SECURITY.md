# Security Policy

## Reporting a vulnerability

Please do not publish passwords, private keys, tokens, or sensitive host details in public issues. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not available, open a minimal issue asking for a private reporting channel without including exploit details or secrets.

## Scope

AccessGuard is a read-only local SSH configuration and permission auditor. It does not connect to remote hosts, execute remote commands, or modify system state.

Reports are welcome for unsafe parsing, incorrect findings, crashes, unexpected file writes, or documentation that could lead to unsafe operation. Include the Python version, operating system, sanitized input, and steps to reproduce.
